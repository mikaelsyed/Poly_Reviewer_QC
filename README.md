# Poly_Reviewer_QC

Reviewer QC toolbar for ArcGIS Pro. No Data Reviewer licence needed.

## Install
Download `Installer/MikaelsReviewerQcToolbar.esriAddinX` and double-click it (close ArcGIS Pro first). The "Reviewer QC" tab appears in Pro.
The installer is rebuilt and replaced with each version (currently 1.1).
